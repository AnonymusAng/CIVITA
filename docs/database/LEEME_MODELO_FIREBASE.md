# Modelo de datos de CIVITA

El archivo `Modelo_CIVITA_Firebase.drawio` contiene tres páginas:

1. Modelo conceptual de reportes y participación ciudadana.
2. Modelo conceptual de preferencias, alertas, eventos y configuración.
3. Modelo documental para Cloud Firestore y Cloud Storage.

## Cómo abrirlo

1. Entre a https://app.diagrams.net.
2. Seleccione **Dispositivo**.
3. Abra `Modelo_CIVITA_Firebase.drawio`.
4. Cambie de página mediante las pestañas inferiores.

## Qué entregar

- El archivo editable `.drawio`.
- Una exportación PDF con las tres páginas.
- La explicación de que las dos primeras páginas son el modelo conceptual solicitado y la tercera muestra su implementación NoSQL.

No use `schema.sql` ni el antiguo diagrama PostgreSQL/PostGIS como modelo físico de la versión Firebase.
